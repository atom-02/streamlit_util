# 문서 유틸리티 (Streamlit)

다섯 가지 문서 도구를 한 화면에 모은 웹앱입니다. 상단 탭으로 전환합니다.

## 도구

### 🧮 수식노트
수식이 포함된 마크다운을 편집하면서 바로 옆에서 실시간으로 미리 보고,
Markdown(.md) · PDF · 한글(HWPX) 세 가지 형식으로 내보내는 도구입니다.

- **편집·미리보기**: 왼쪽에 마크다운 원문을 쓰면 오른쪽에 실시간으로 렌더링됩니다
  (Streamlit 내장 수식 렌더링 사용, `$…$` / `$$…$$` 인식)
- **파일 열기**: 기존 `.md`/`.txt` 파일을 불러와 이어서 편집
- **Markdown 저장**: 편집 중인 원문을 `.md` 파일로 다운로드
- **PDF로 내보내기**: `md2hwpx_app`의 마크다운 파서(`parse_markdown`/`parse_inline`)로
  구조를 분석하고, reportlab(Platypus)로 문단을 흘려 쓰며, 수식은 matplotlib의
  mathtext로 그린 이미지를 문장 안에 인라인으로 끼워 넣습니다. 한글 폰트는
  `qr_tool`이 등록해 둔 폰트를 그대로 재사용합니다 (기본 문법은 지원하지만
  `\begin{align}` 같은 고급 LaTeX 환경은 지원하지 않을 수 있음)
- **한글(HWPX)로 내보내기**: 같은 원문을 `md2hwpx_app.convert_md_to_hwpx_bytes`로
  그대로 변환 — 편집 가능한 한글 수식 개체로 들어가며, Markdown → HWPX 변환기와
  동일한 변환 로직을 공유합니다
- **새 노트**: 확인 후 내용을 비움

### 📄 Markdown → HWPX 변환기
LaTeX 수식이 포함된 마크다운(.md)을 한글(HWPX) 문서로 변환합니다.
수식은 편집 가능한 한글 수식 개체로, 이미지는 편집 가능한 그림 개체로 삽입되며,
변환 로직은 파이썬 표준 라이브러리만 사용합니다. 출력 양식은 기존 **A4**와
시험지용 **A4_2단**, **B4_2단** 중에서 선택할 수 있습니다.

- 수식: 인라인 `$...$` / `\(...\)`, 디스플레이 `$$...$$` / `\[...\]` (ChatGPT 등 AI가
  흔히 쓰는 `\(...\)`/`\[...\]` 델리미터도 인식)
- 집합 중괄호: `A=\{1,2,3\}`와 `A=\left\{x\mid x>0\right\}`를 한컴에서
  실제로 표시되는 `LEFT { ... RIGHT }` 수식으로 변환. 집합 안의 원소 사이는 `~`로
  한 칸 띄우고, 조건 구분선 `\mid`는 앞뒤가 한 칸씩 띄어진 `~ vert ~`로 변환
- 논리 함의: LaTeX `\implies`를 양쪽에 수식 공백을 둔 한글 명령 `~ RARROW ~`로 변환
- 이미지: `![설명](파일명)` — 같은 이름의 이미지 파일을 함께 업로드하면 편집 가능한
  그림 개체(PNG/JPEG/GIF/BMP)로 삽입 (디스크에 쓰지 않고 메모리에서만 처리)
- 서식: 제목(`#`~`######`), **굵게**, 가로줄(`---`), 표(`|...|`)
- 출력 배치: 기본 A4 또는 A4/B4 2단 양식 선택, 2단 양식의 구분선 유지,
  문항 사이 빈 줄 2줄 삽입
- 띄어쓰기: `$x$ 의 값`처럼 수식과 조사 사이를 띄어 쓴 원문은 `x의 값`으로 붙임.
  조사가 아닌 낱말(`$x$ 그리고`)은 띄어 쓴 그대로 유지

#### 변경 사항 (2026-10-02)

설치된 한글에서 수식을 하나씩 직접 렌더링해 보면서, 글자로 찍히거나 모양이 틀리던 변환을
바로잡았습니다. 아래 대응은 모두 한글 렌더링으로 확인한 것입니다.

- 이름을 그대로 넘겨 글자로 찍히던 명령을 한컴 키워드로 대응: `\perp`(`BOT`),
  `\parallel`, `\setminus`, `\supset`, `\ni`, `\neg`, `\land`, `\lor`, `\ell`, `\iint`,
  `\iiint`, `\bigcup`, `\bigcap`, `\lfloor`·`\lceil`, `\langle`·`\rangle`(`LEFT < … RIGHT >`),
  `\overrightarrow`, `\underline`, `\widehat`
- `\Rightarrow`·`\Leftarrow`·`\Leftrightarrow`·`\iff`를 `RARROW`·`LARROW`·`LRARROW`로 변경
  (기존 `=>`는 한글에서 화살표가 아닌 글자로, `<=`는 ≤ 로 찍힘)
- 간격 명령을 버리지 않고 한컴 공백으로 변환: `\,` → `` ` ``, `\;`·`\:`·`\ ` → `~`,
  `\quad` → `~~`, `\qquad` → `~~~~`
- 로만체가 뒤 글자까지 번지던 문제 수정: `\mathrm{P}(A)`의 `A`가 곧게 서지 않도록
  `{rm P it}` 꼴로 닫음. `\text{...}`는 곧은 글씨로, 양끝 공백은 `~`로 유지
- `\mathbb{R}` 등은 ℝ·ℕ·ℤ·ℚ·ℂ 로, `\mathcal{L}`·`\mathscr{F}`는 필기체 글자(ℒ, ℱ)로 변환
- `\underbrace{…}_{…}`·`\overbrace{…}^{…}`, `\overset`·`\underset`·`\stackrel`,
  `\xrightarrow{…}`, `\substack{…}`, `\not\subset` 같은 부정, `\boxed{…}` 지원
- `aligned`/`align` 환경에서 `&`를 유지해 등호 위치로 줄을 맞춤. `array`, `Bmatrix`,
  `split`, `gather` 환경 추가. `Vmatrix`는 이중 세로줄로 표시
- 수식 상자 크기를 글자 수 어림 대신 실제 조판에 가깝게 계산. 한글이 같은 수식에 대해
  직접 저장한 상자 47개에 맞춘 값으로, 세로·기준선은 몇 % 안, 가로는 대체로 10% 안에서 일치
- 2단 양식에서 표와 그림이 단 밖으로 넘치던 문제 수정: 표 너비와 그림 최대 너비를 고른
  양식의 단 너비에 맞춤. 그림은 원래 크기(96dpi)로 넣고 단보다 클 때만 줄임
  (기존에는 작은 그림도 150mm 로 늘림). 가로줄(`---`) 길이도 단 너비에 맞춤
- 표 구분 행 `|:-:|`(대시 하나)을 본문 행으로 싣던 문제와, 셀 안 수식의 `|`(절댓값)가
  칸을 나누던 문제 수정
- 별행 수식(`$$…$$`, `\[…\]`)을 가운데 정렬, 코드 블록의 ``` 줄은 싣지 않음
- 수식 뒤 조사 붙여쓰기 추가 (위 "띄어쓰기" 항목)

#### 최근 변환 개선 사항 (2026-09-21)

AI가 작성한 수학 문제 Markdown과 PDF에서 AI로 추출한 Markdown을 다시 HWPX로 옮기는
사용 흐름을 기준으로 변환 규칙을 보강했습니다.

- 백틱 코드 구간을 수식보다 먼저 인식하여 `` `$` ``와 `` `$$` `` 같은 설명용 기호가
  수식으로 잘못 변환되거나 뒤의 문장을 삼키지 않도록 수정
- Markdown 제목, `**굵게**`, 글머리표·번호 목록을 각각의 문단과 서식으로 보존
- `pmatrix`, `bmatrix`, `vmatrix`/`Vmatrix`를 각각 한컴의 소괄호 행렬, 대괄호 행렬,
  행렬식(`dmatrix`)으로 구분하여 변환
- `\left ... \right`를 한컴 `LEFT ... RIGHT`로 바꾸어 큰 분수·합·적분 주위의 괄호가
  내용 크기에 맞게 확대되도록 수정. 집합 중괄호 `\{...\}`도 표시용 괄호로 유지
- `aligned`/`align` 환경을 `eqalign`으로, `\sqrt[n]{x}`를 한컴 문법
  `root {n} of {x}`로 변환 (2026-10-02부터 `&`를 유지해 등호 위치로 정렬)
- `\emptyset`, `\forall`, `\exists`, `\subseteq`, `\supseteq`, `\therefore`,
  `\because`, `\ldots`, `\cdots`, `\vdots`, `\ddots`와 주요 글자 장식을 추가
- `\mathbf`, `\mathrm`, `\mathit`의 글꼴 의도를 보존하고, 한컴에 직접 대응하는
  캘리그래피 글꼴이 없는 `\mathcal`은 기울임(`it`)으로 안전하게 대체
  (2026-10-02부터 대문자는 필기체 글자 ℒ·ℱ 등으로 변환)
- 위 변환 규칙은 단위 테스트로 검증하며, 생성된 수식은 편집 가능한 한글 수식 개체로 유지

### 📷 시험지 문항 캡처 → HWPX (2단)
수능·모의평가 **수학 영역** PDF의 문항을 하나씩 그림으로 잘라내어, 원본처럼 2단으로
배치한 한글(HWPX) 문서를 만듭니다. 글자·수식 편집은 되지 않지만 원본 모양이 그대로
유지됩니다. 잘라낸 문항 PNG는 ZIP으로도 받을 수 있습니다.

- 문항 번호(`1.`, `23.` …)의 위치를 PDF 텍스트 레이어에서 찾아 같은 단 안에서 다음 문항
  직전까지를 잘라냄. 제목 밑 괘선·쪽번호·"확인 사항" 상자는 자동 제외
- 문항 번호가 다시 작아지는 곳(30 → 23)을 새 구간(선택과목)으로 보고 구간마다 새 쪽에서 시작
- 옵션: 용지 B4(수능 규격, 약 91%)/A4(약 75%), 문항 사이 빈 줄 수, 단 구분선,
  5지선다형/단답형 제목, 구간 이름
- 평가원 형식(A3 2단, 공통 1~22 + 선택 23~30)에 맞춰져 있어 다른 형식은 인식이 안 될 수 있음

### 📑 PDF 쪽 추출 · 병합기
수능·모의고사 PDF에서 원하는 쪽만 뽑거나, 여러 파일을 한 권으로 묶습니다.

- **쪽 추출** — 각 PDF에서 지정한 쪽만 뽑아 파일별로 저장 (여러 개면 ZIP 일괄 다운로드)
- **하나로 합치기** — 지정한 순서대로 병합, 파일명 기준 북마크(목차) 자동 생성
- 쪽 지정: `9-12`(범위), `1, 3, 5`(낱장), `1, 9-12, 20`(혼합)

### 🔗 QR코드 안내문 생성기
제목과 링크 주소를 입력하면 QR코드가 담긴 안내문을 PDF 또는 한글(.hwpx)로 만듭니다.

- 제목은 크게, 링크 주소는 제목 바로 아래에 부제목처럼 작고 가깝게 배치(왼쪽 정렬), QR코드는 페이지 가로 중앙에 크게 배치
- 내용 길이와 상관없이 위·아래 여백이 자동으로 균형 있게 맞춰짐
- PDF와 한글 문서는 여백·글자 크기·QR 크기까지 같은 계산식을 써서 동일한 모양으로 생성됨
- 한글 문서의 제목·링크는 편집 가능한 글자, QR코드는 그림 개체로 들어감 (링크는 일반 글자, 클릭 링크 아님)

## 로컬 실행

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

브라우저가 자동으로 열립니다(기본 http://localhost:8501).

## Streamlit Community Cloud 배포 (무료)

1. 저장소 전체를 GitHub에 올립니다.
2. https://share.streamlit.io 에 GitHub 계정으로 로그인합니다.
3. **Create app → Deploy a public app from GitHub** 를 선택합니다.
4. 저장소(Repository), 브랜치(Branch), 메인 파일 경로(`streamlit_app.py`)를 지정합니다.
5. **Deploy** 를 누르면 공개 URL이 생성됩니다.

## 파일 구조

```
streamlit_app.py    메인 진입점 (탭으로 다섯 도구 전환)
susik_note.py       수식노트: 편집·미리보기 + Markdown/PDF/HWPX 내보내기 (render(),
                     md2hwpx_app·qr_tool 재사용)
md2hwpx_app.py      Markdown → HWPX 변환 로직 + UI (render())
capture_tool.py     시험지 문항 캡처 → 2단 HWPX 로직 + UI (render(), md2hwpx_app 재사용)
pdf_tool.py         PDF 추출·병합 로직 + UI (render())
qr_tool.py          QR코드 안내문(PDF/한글) 생성 로직 + UI (render(), md2hwpx_app 재사용)
test_susik_note.py       수식노트 회귀 테스트
test_md2hwpx_app.py      Markdown → HWPX 변환기 회귀 테스트
requirements.txt    streamlit, pypdf, pymupdf, qrcode[pil], reportlab, matplotlib
packages.txt        fonts-nanum (PDF에 한글을 임베드하기 위한 apt 패키지)
```

다섯 모듈 모두 `render()` 함수만 노출하며, `st.set_page_config()`는
`streamlit_app.py`에서 한 번만 호출합니다.

## 참고

- HWPX 출력은 한글 2014 이상에서 열립니다.
- 수식 상자 크기가 처음에 어색하면, 한글에서 그 수식을 더블클릭해 수식 편집기를
  한 번 열었다 닫으면 정확히 다시 계산됩니다.
- 업로드한 파일은 서버에 저장되지 않고 세션 메모리에서만 처리됩니다.
